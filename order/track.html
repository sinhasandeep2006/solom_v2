What the stages mean

  1. Paid

    Set only when the payment gateway confirms it to our server directly. Cash-on-delivery orders skip straight to Packed.

  2. Packed

    Usually within 2 working days of the order.

  3. Shipped

    You get the courier name and an AWB number you can follow on their site.

  4. Delivered

    Return window starts from this date — see the returns policy.
